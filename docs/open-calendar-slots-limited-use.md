#### Limited Use Policy

Open Calendar Slots's use and transfer to any other app of information received from Google APIs will adhere to [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

Specifically:

*   Open Calendar Slots only requests the minimum scopes required for its single purpose: `https://www.googleapis.com/auth/calendar.readonly` (to compute free time) and `https://www.googleapis.com/auth/userinfo.email` (to show which account is signed in).
*   Data accessed via Google APIs is never transferred to any third party.
*   Data accessed via Google APIs is never used for advertising, including personalized or retargeted advertising.
*   Data accessed via Google APIs is never read by humans except as required for security purposes, to comply with applicable law, or with the user's explicit consent.
*   No data accessed via Google APIs is stored on any server operated by the Company. All processing happens locally on the user's device.
